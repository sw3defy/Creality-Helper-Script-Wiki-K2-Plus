# Install Menu — K2 Plus

The install menu provides optional features for the Creality K2 Plus and Combo.

!!! danger "Safety review in progress"
    The unmerged maintenance branch deliberately blocks several installers, including Moonraker Extensions, fan controls, KAMP, Timelapse, and improved shapers. **Do not use the historical installation order as a recommendation to install everything.** The published Helper Script may differ from the branch under review.

## Required safeguards

Review the [Safe Update Audit](../safe-update-audit.md), inspect the active configuration, back up files off-printer, and use only validated firmware-specific procedures. HelixScreen requires an immediate reboot following installation; do not hard-reset during a slow first boot.
