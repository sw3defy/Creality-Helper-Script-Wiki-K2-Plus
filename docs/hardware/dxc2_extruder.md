# DXC2 extruder — K2 Plus

An upgraded extruder for the K2 series printers.

---

## Fimrware Configuration

Make sure you have followed the [Install Helper Script](../scripts/helper-script-installation.md) section, then from the `[Install] Menu` install **DXC2 Extruder**.

This will make the required configuration for the extruder.
