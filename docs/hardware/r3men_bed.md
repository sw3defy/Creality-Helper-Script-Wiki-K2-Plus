# R3Men Graphite Bed — K2 Plus

A low-warp, quick heating graphite bed.

---

## Fimrware Configuration

Make sure you have followed the [Install Helper Script](../scripts/helper-script-installation.md) section, then from the `[Install] Menu` install **R3Men Graphite Bed**.

This will update `printer.cfg` to the required configuration for the bed.
